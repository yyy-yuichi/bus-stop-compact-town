# 背景地図の施設を検索・選択へ反映（2026年9月11日）

スーパーの「食」を買い物かごに変更し、施設を22件から1,135件へ拡充した。背景の地図画像とは別に、同じOpenStreetMapの施設要素を取得してアプリへ取り込む。クリック、名前検索、詳細表示、種類の切替、共有リンクの対象になる。

既存22件のID・形状・公式照合記録は保持。追加1,113件には`verification_status=osm_unverified`を設定し、公式所在地・公式URL・照合日は空欄にした。OSMにある住所・ウェブサイトは別欄に保存する。登録がなければ詳細にその旨を表示し、推測で補わない。病院の診療内容、営業時間、入口、現地の位置精度、現在の営業は確認していない。

OSMの点は元座標、way・relationはOverpassが返した外接矩形の中心を代表点とする。建物外形や入口として表示しない。表示は分類に対応する色の点から始まり、ズーム13以上ではアイコンになる。画面外の施設を描画せず、施設一覧は24件ずつ、検索結果は12件ずつ追加する。全件の名前検索は拡大率に依存しない。

背景画像の文字・記号は表示フィルターで消えない。今回の取得時点、対象分類、名前の有無と背景側の表示条件により、背景に見える施設との完全一致は保証しない。件数は収録レコード数であり、同名要素や建物と敷地の別登録などの重複が残る場合がある。

## 取得条件と出典

山口県のOSM行政界`ISO3166-2=JP-35`内を対象とした。条件は`shop=supermarket/chemist/convenience/mall/department_store`、`amenity=hospital/clinic/doctors/pharmacy`、`healthcare=hospital/clinic/doctor/pharmacy`。OSMの分類を採用し、チェーン名から別分類へ推測変更しない。`shop=chemist`と`amenity=pharmacy`の両方がある場合はドラッグストアとする。

取得先は[Overpass Private.coffee](https://overpass.private.coffee/)。[OSMのOverpass公開サーバー一覧](https://wiki.openstreetmap.org/wiki/Overpass_API#Public_Overpass_API_instances)に掲載されたサービスを使用した。取得日2026年9月11日、応答内のOSMデータ基準日時は**2026年7月28日02:16:18 UTC**。この日時は各施設の営業確認日ではない。画面表示時にOverpassへ問い合わせる方式ではなく、取得結果を静的ファイルとして配布する。

1,182要素から、名前なし45、使用停止の登録1、既存と同じOSM ID 21、既存建物内の同名点2を除外した。同名点2はゆめタウン長府・フジグラン山口で、名称一致と既存ポリゴン内への包含を確認して既存IDを優先した。それ以外の近接要素を距離だけで統合しない。取得元ID、除外理由、データSHA-256を記録した。

## 再生成と連携

```sh
python scripts/import-osm-facilities.py
python scripts/test-osm-facilities.py
npm run test:places
npm run build
node scripts/verify-release.mjs
python scripts/export-integration-index.py osm-facilities-20260911
```

保存済みの原資料から再生成でき、OSMの再取得を必要としない。同じ入力で再実行した出力の一致をテストする。新規取得用の`--fetch`は保存済み原資料がある場合に上書きを拒否する。将来の更新時は、別の日付の原資料として管理し、既存IDの変更・削除・重複候補を確認する。

施設IDは既存IDに加えて`osm-node-...`、`osm-way-...`、`osm-relation-...`を使用する。最新のID一覧・共有リンクは`outputs/osm-facilities-20260911/id-index/`。施設CSVには確認状態、登録住所・ウェブサイト、代表点の経度・緯度も含む。ポリゴンはCSVに代表座標を推測追加せず、GeoJSONの形状を参照する。

徒歩圏の道路・計算・対象7地点とおのだサンパーク1施設は維持している。新しい施設を「徒歩で到達できる候補」としては追加していない。コーディネーターから新しい徒歩圏データを受領後、対象ID・形式・入口や範囲包含の扱いを照合して接続する。

## 検証

データ取込の5テストで、分類の区別、危険なURLの除外、同じ入力による再生成の一致、既存22件の完全保持、使用停止・無名・私有の除外、ポリゴンの穴を考慮した包含を確認。全1,135施設のID・出典・座標・確認状態と全5,560場所リンク、既存バス停・徒歩経路・道路原資料、ビルドと公開ファイルの整合検証が成功した。CSVは保存後に全行を読み戻して照合した。

PC幅1280とスマホ幅390で、スーパーのアイコン、病院の検索・選択・住所未登録表示・出典日時、7種類のフィルターを確認。病院を非表示にしても検索から選ぶと再表示されること、一覧を24件から48件へ増やした際に25件目へフォーカスが移ることを確認した。既存の徒歩圏試作はサンパーク1施設の候補を保ち、ブラウザー実行エラーは検出されなかった。実機のタッチ操作と追加施設の現地確認は未実施。
