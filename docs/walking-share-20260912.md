# 徒歩条件を含む共有リンク（2026-09-12）

合意済みの「バス停を起点に徒歩で使える生活機能を可視化し、チームで試す」という目的に沿い、共有リンクへ徒歩時間と歩く速さを追加した。

## 動作

- 徒歩圏試作のバス停では「この徒歩条件のリンクをコピー」を表示し、バス停ID、徒歩5分または10分、時速3kmまたは4kmを共有する。共有する条件をボタンの下にも表示する。
- 時間・速度を変更するとアドレスも更新される。リンクを開いた場合と再読み込みで同じ条件に戻る。施設詳細から元のバス停へ戻った場合も条件を維持する。
- 以前の条件なしリンクは互換性を保ち、徒歩10分・時速4kmで開く。施設・国のバス停のリンクは場所だけを共有し、徒歩圏対応を付加しない。
- 条件付きリンクの時間と速度はそれぞれ1つずつ必要。範囲外・空値・重複・片方だけの指定は案内を出し、誤った条件で計算しない。
- 地図の拡大率、検索語、施設を開く前のバス停、経路強調のオン・オフは共有対象に含めない。

試用例：[スポーツセンター前・地点2／徒歩5分・時速3km](https://yyy-yuichi.github.io/bus-stop-compact-town/#kind=pilot&id=node%2F5127585173&minutes=5&speed=3)。公開版で同じ条件を復元できることを確認済み。
