# バス停から歩けるまち：最初の徒歩圏試作

目的は、バス停を起点に徒歩で利用できる買い物などの生活機能を可視化し、コンパクトタウンを考えること。交通データの精査はそのための基盤と位置付ける。

## 今回の体験

地図の「おのだサンパーク周辺で試す」から始め、7停留所の出発点、5分・10分、時速3km・4kmを切り替える。到達できる道路を緑／黄土色で描き、おのだサンパークの建物付近へ届く場合に買い物候補として表示する。候補の経路を強調できる。スマホは地図と下部パネルを併用する。

今回の対象施設は1施設。県内の登録済み19施設をすべて徒歩圏判定する機能ではない。対象地域外のバス停は試作地域へ案内する。

## 計算

- OSM道路を限定範囲で取得し、2,818ノード・3,023区間の徒歩グラフへ変換。交差は共通ノードだけで接続する。
- 徒歩禁止や私有の指定を参照。徒歩の明示許可がある場合は足のアクセス指定を優先。自動車の一方通行を歩行者にそのまま適用せず、歩行者一方通行を別扱いにする。
- 自動車専用道路、徒歩許可のないtrunk系、条件付きアクセスで判断できない区間、面として登録された広場等を除く。
- 最寄り道路への接続は30m以内、接続距離を含めた最短距離をDijkstra法で計算。予算距離の途中までしか届かない道路は途中で切る。
- 施設候補は建物外形から25m以内の道路上の地点までの到達で判定。入口までの到達ではない。施設カードにその限界を表示する。
- 速度、平面距離に基づく概算。信号待ち、坂道や階段の速度変化、工事、現地の横断可否は未反映。道の記録漏れ・接続漏れも残り得る。

## データと再現

OSM取得日：2026-09-08。原本取得範囲は経度131.158〜131.187、緯度33.974〜33.999。出典は© OpenStreetMap contributors、ODbL 1.0。

保存用原本は道路・参照ノード・計算に必要なタグだけを残した `work/walking-pilot-20260908/onoda-walking-source.osm`。編集者等のメタデータを除き、取得元・原本と抽出原本のハッシュを同ディレクトリのsource-manifest.jsonへ保存する。公開配布用はpublic/data/walking-onoda.json。

1. Pythonでscripts/build-walking-pilot.pyを実行して公開JSONを再生成。
2. Pythonでscripts/test-walking-source.py、Node.js 24でnpm run test:walkingを実行。
3. npm run build、node scripts/verify-release.mjsで配布物を検証。

テストは道路途中の到達境界、接続しない交差道路、歩行者一方通行、出発点と道路の接続距離、最短経路の更新、施設判定、実データ7停留所、アクセス・バリアの条件を対象とする。OSM原本の地理的正確性を保証するものではない。
