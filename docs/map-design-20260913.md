# 地図の密度とスマホ表示の改善（2026-09-13）

## 変更

広域で国・市のバス停5,325登録と施設1,130件を一度に重ねていたため、白い点が密集して地形や地名を読みにくくしていた。バス停は広域で件数のまとまりを表示し、数字を押すと段階的に拡大、ズーム14以上で個々の元の登録位置を表示する。隣り合う数字にも間隔を確保し、選択中のバス停は常に強調する。

スマホは県中央部を一段拡大して開く。「県全体」で全域、「岩国市」「光市」で各市の登録範囲へ移動できる。検索欄の外側の大きな白い枠をなくし、地域ボタンを小さな丸い形へ変更。ヘッダーも薄くした。背景地図の彩度を下げ、バス停と徒歩圏を読み取りやすくした。検索結果・設定は開いたときだけ白いパネルを表示する。

施設の地図表示は、選択中のバス停・徒歩時間・歩く速さに対応した候補に限る。出発点や時間を変えた際に前の候補が残らないよう条件を照合する。施設の直接検索・一覧・共有リンクから開く場合は、その施設を表示する。バス停詳細を閉じると候補のマーカーも消える。従来のOSM徒歩圏でも施設詳細を開いた間は経路描画を隠し、戻ると再表示する。

数字は表示をまとめた登録件数であり、物理的な停留所の統合結果ではない。国4,418件・岩国市735件・光市172件の原本IDと座標、施設1,135件、従来のOSM7地点を維持する。国の徒歩圏と市の登録点を別の出発点として扱う。新しい道路計算やR2の変更は行っていない。

## 検証

- 型検査、施設データ検査、検索・共有リンク、国・市のカタログ、従来徒歩計算、焼き込み徒歩圏、施設候補の検査が成功。
- 表示検査で5,325IDの欠落・重複・原本座標変更がないこと、隣接する数字が重ならないこと、ズーム14以上で個々の登録に戻ることを確認。ズーム9では15グループ、14では5,325登録となる（地図へ描画するのはその時の画面周辺）。
- 古い出発点・徒歩時間の施設候補が混入しないこと、候補0件・未選択・未取得・分類フィルター・参考施設の直接リンクを検査。
- スマホ390×844で初期表示、県全体、光市への移動、数字から個別バス停への段階的な拡大、市の停留所選択、国の光駅15/10/5分候補6/3/2件、施設詳細往復とバス停を閉じた際の候補非表示を確認。
- 「こすもす 高栄」の検索から施設選択・再読込復元、従来OSMの5分・時速3kmリンクと1施設候補を確認。PC1280×900で広域の密度と表示設定を確認。通常操作のブラウザー警告・エラーは0。
- R2 URLを含む公開用ビルド18ファイルについて、公開ファイルの許可リスト、原本一致、バス停・施設件数、徒歩圏をサイトに同梱しないことを確認。
