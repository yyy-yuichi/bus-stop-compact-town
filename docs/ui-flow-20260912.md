# 3：バス停・徒歩圏・施設の画面導線（2026-09-12）

## 対象と結果

2の日常の買い物先拡充・施設分類点検を区切り、a808a07の画面を対象に3の導線整理を実施した。施設35件の調査は再開していない。分類保留13件は理由付きで維持している。新しい徒歩圏データは未受領。

- 買い物候補に「施設の詳細を確認」を追加し、所在地・公式サイト・位置の注意書きへ進めるようにした。
- 施設詳細を開いても元のバス停と徒歩条件を保持。戻るボタン・×・Escapeで、5分／10分、歩く速さ、経路の強調、候補欄のスクロールを保って徒歩圏へ戻る。
- バス停詳細の徒歩圏を共有リンクより先に配置。「結果を見る」はPCでも使え、候補見出しへフォーカスと表示を移す。
- OSM試作の詳細に「県全体のバス停に戻る」を常設。国土数値情報の4,418件と、徒歩圏試作のOSM7地点を見出しと案内で区別した。
- 検索結果から場所を選んでも検索語を残し、「検索結果に戻る」で結果を再表示。スマホの検索結果が詳細パネルに隠れないよう表示順を調整した。
- 全体表示ボタンの読み上げラベルを、通常地図と試作で切り替えた。
- 使い方ページへ往復操作を追記。前工程の施設点検後も古いままだった件数表記を、通常1,130＋参考5件へ合わせた。

施設の開閉中、バス停パネルは状態保持のため存在するが非表示にし、操作・読み上げ・Escapeの対象から外す。独立した施設リンクを再読み込みした場合は、過去のバス停や徒歩条件を作り出さない。

## 変更しないデータ境界

国土数値情報4,418件の代表位置とOSM試作7地点の対応は未確認。徒歩圏は既存道路データとおのだサンパーク1施設だけが対象。施設1,135件のID・分類・位置、国のバス停、道路グラフは変更していない。入口・敷地内通路は未確認であり、未計算地域への到達圏を表示しない。
