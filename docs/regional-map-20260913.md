# 岩国市・光市の表示と画面整理（2026-09-13）

ユーザーの継続要望は「以前多かった岩国市・光市のデータを通常の地図でも見たい」「ポップアップや説明に頼らない画面にしたい」。確認の返答で作業を止めず、実装・検証・公開・Drive保存を一続きで扱う。

## 修正した原因と動作

通常マップが国土数値情報4,418レコードだけを読み、既存の市データ907レコードは比較マップ専用だった。国を基本とする構成を保ち、岩国市735・光市172を通常マップでも別の点として表示・検索・共有できるようにした。検索欄の下に県全体・岩国市・光市の移動ボタンを置いた。地域ボタンは市の登録点を含む範囲への移動で、行政界による絞り込みではない。

国の代表点と市の登録点は元ID・座標・路線参照を維持し、重複を統合しない。市の点は茶色で表示。市の点の徒歩圏は未作成と短く示し、300m以内の国の計算起点へ明示的に移るボタンを付けた。接続不可と分かっている国の起点は案内から除く。近くの国の徒歩圏を市の点の結果として使わない。市原資料の既存採用範囲だけを表示し、由宇改正関連の保留65件は今回の追加対象外。

## 画面の整理

- PC・スマホとも初期状態は検索と地域移動だけ。種類の切替・施設一覧・従来試作は設定内に置く。検索語が残った状態でも設定を開ける。
- バス停の長い注意文・出典、施設の点検理由・未確認説明、徒歩計算の説明、地図の凡例は閉じた状態から必要時だけ開く。分類確認中の短い表示は維持。
- 施設候補を、名称・種類・近くの道路までの時間が分かる押せる一覧にする。行ごとに繰り返していた説明と詳細ボタンを整理。
- PCの詳細欄は内容が短ければ高さを縮め、空の大きなパネルを出さない。施設・バス停を選んだ時だけ詳細を開く。

## 検証

全市レコード907件のID・座標・路線・市名を照合し、国の4,418件と別IDのまま併存することを検査。誤った市レコード、未解決路線参照、国への誤った徒歩圏結合を拒否する。共有リンク6,467件、従来28条件、新しい国の13,254条件と不正リンクが成功。既存の道路・施設判定、型・施設データ検証も成功。

国の北河内駅と光駅の公開済み徒歩圏2ファイルを追加確認。道路上の距離・近接位置と5/10/15分の候補数を検査し、従来8地点と合わせて10地点の実データ検査が成功。取得記録と出典は [サンプル資料](../data-sources/regional-map-20260913/README.md)を参照。

実画面では市の地域移動、北河内駅・浅江中学校前の検索、登録点の共有復元、近くの国の起点への移動を確認。スマホ390×844で、光駅の5/10/15分候補2/3/6件、医療に絞った状態から詳細への往復、10分リンクの再読み込みを確認。説明・凡例を開閉でき、未接続の市の点に他の徒歩圏を表示しない。

市データ取得を検証用サーバーで503にすると、国のデータは表示を続け、市データの再試行を案内。共有先の市IDを失わず、復旧後の再試行で元の浅江中学校前へ戻った。通信失敗を不存在や0件として扱わない。

ローカルからR2への直接取得は配信側CORSにより許可されていなかった。公開先オリジンはHTTP 200とCORS許可を確認。設定を変更せず、ローカルの画面操作は保存済みサンプルを配信して検証し、実際のR2取得は公開後に別途確認する。
