# 国土数値情報を基本にする変更

通常マップのバス停を国土数値情報2022年度版の山口県4,418レコードに変更。比較マップは引き続き3出典を個別に確認できる。

## 停留所と乗り場

`src/stopCatalog.ts`で国の原本を表示用カタログへ変換する。代表位置の座標・名称・出典を維持し、`location_kind: representative`を設定する。現地の乗り場位置や現在の運行を確認済みとは扱わない。

`stop_area_id`は現時点では版付き出典レコードIDと同じ。版をまたぐ全国共通IDではない。将来データを更新する際は旧レコードとの対応を確認し、このIDを維持するか対応表で移行する。同名・近接だけで同一停留所と決定しない。

将来の乗り場は独立した`BoardingPoint`レコードで、親の`stop_area_id`、乗り場ID、座標、方向（不明ならnull）、出典URL・原本ID・確認日を持つ設計。現在は乗り場レコードの整備・取込・選択UIは未実装。代表位置から上下線を生成しない。追加時は自治体・事業者等の資料との対応と利用条件を確認する。

## 徒歩圏試作

既存の7地点はOSMのまま別モードにする。通常の代表位置へ徒歩計算結果を流用しない。試作ボタンでOSMの7地点へ切り替え、県全体に戻るボタンで国のデータへ戻る。原点・道路網・計算方法は維持。県内全域や国の代表位置の徒歩圏は未対応。

## 検証

カタログ検証：4,418件、原本不変、座標不変、ID重複拒否、独立した7地点の保持、未確認の親子関係を作らないことを確認。既存の徒歩圏テスト、型検査、施設検証、ビルド、公開物検証を実行。
