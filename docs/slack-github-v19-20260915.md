# Slack報告文案：乗り場別表示・徒歩圏のGitHub反映

バス停と暮らしマップについて、同じ名称のバス停でも乗り場ごとの場所・番号・方面を選び分けられるようにする更新を、GitHubの公開候補ブランチへ反映しました。

今回の主な内容です。

- 公式資料と既存の原位置データを照合し、確認できた乗り場を原IDごとに区別
- 確認できた乗り場では、各原点からの徒歩5・10・15分圏と周辺施設を表示
- 船木鉄道の公式せんナビから74原点を追加調査し、山陽小野田市の7原点へ徒歩圏を新規追加
- バス停アイコンを見やすくし、選択時は滑らかに地図を移動
- 周辺施設の詳細を開いても徒歩圏表示を保持
- 最新の全体表示への復帰修正も取り込んだ状態で検証

資料だけでは道路側を確定できない船木鉄道67原点、追加取得したいわくにバス238原点、和木駅などは、推測で埋めず保留理由を残しています。今回の反映を全県の乗り場確定完了とは扱っていません。
