# 案内図を実際に操作するための準備（2026-09-14）

ユーザーの「マップは使えないとわからない」を受け、画像用の試案を通常アプリへ組み込み、公開用ビルドと操作検証を行った。**未公開**。前回の自動承認レビューが求めた具体的なマージ・公開の承認を待つ。

## 操作できる状態にした内容

- 案内図の生成りの陸地・青緑の海・整理した道路名を通常アプリに適用。設定で「案内図」と従来の「標準」を切り替えられる。
- 選択中のバス停名、少数の施設の名前を地図に表示。施設の元の位置は保ち、名前に引き出し線を付ける。施設・バス停・検索欄・地図コントロールと重なる名前は省略する。施設が表示範囲に12件を超えているときは、名前は選択中の施設だけにする。
- 徒歩圏の線は3px、坂道の線は1.3px。凡例も同じ比率に揃え、不要になった白い重ねを除去。計算方法、起点、道路、距離、勾配の判定は変更していない。
- 「買い物・医療・暮らし」の選択を施設一覧と地図に反映。施設名をタップして詳細を開き、時間と分類を維持して戻れる。
- 試案の光駅・徳山駅前だけに限定した配信設定を使わず、既存の全県用R2配信URLでビルドした。R2の設定やデータは変更していない。
