# 徒歩圏PR #1の統合（2026-09-12）

対象は [PR #1](https://github.com/yyy-yuichi/bus-stop-compact-town/pull/1)、`gunsow911` の `feature/isochrone`（受領時 `21ab140a`）。現在の公開版 `558d87a` と、その後の引き継ぎ文書 `364d674` に統合する。ユーザーから競合解消とマージの依頼を受けて実施。マージ後にユーザー自身がコーディネーターへ返信するため、こちらからメッセージは送信しない。

## 統合内容

- PRの事前計算、標高・勾配、距離グラデーション、急坂表示、R2からの遅延取得を採用。国のバス停を選ぶと、時速4km・最大15分相当の新しい徒歩圏を表示する。
- 国のバス停4,418レコードは元のID・名称・座標・事業者・路線を維持。同じP11原資料の座標を小数5桁に丸めた3,946計算起点へ接続する。同座標の原資料レコードは徒歩圏を共有するが、マップのIDと共有リンクは統合しない。OSM停留所を近さだけで国の停留所へ対応付けない。
- `bus_stop.geojson` は従来のOSM原本1,085件として維持。新しい計算起点は `baked-bus-stops.geojson` に分離し、再生成・計算・テストの参照先も更新。
- 新しい表示は `BakedWalkingPanel.tsx` / `bakedWalking.ts` にまとめ、従来の `WalkingPanel.tsx` / `walking.ts` を維持。7地点の5/10分・時速3/4kmの共有、買い物候補、施設詳細への往復を保つ。検索・施設1,135件・7分類・参考表示も維持。
- 新しい徒歩圏の施設候補抽出はPR側でも未実装。自動抽出済みとせず画面へ明示し、地図と検索から施設を確認できるようにした。新方式は最大15分相当の連続表示で、従来試作の時間・速度切替とは区別する。
- 接続不可の289地点はローカルの一覧により案内し、不要な404取得を避ける。それ以外の404・配信失敗は再試行できるエラーとして扱う。異なる起点IDの応答、不正な距離・予算・階段フラグを拒否し、バス停切替直後に前の徒歩圏を描かない。
- `.gitignore`、出典ページ、リリース検査、BusStopDrawer、BusStopLayer、WalkingPanel、typesの7競合を解消。両方の計算テストと原資料・検索・共有の検査をCIに組み込んだ。

## 受領データ・出典

- P11原資料4,418件を現行レコードと順番・名称・座標まで全件照合し、一致。ブラウザー用の座標IDも全件が新しい3,946計算起点に存在することを確認。
- GitHub変数 `WALK_DATA_URL` は設定済み。配信先は `https://pub-64cdb45739c446ef86342de34ccd47a6.r2.dev/data/walk`。一覧3,657件と接続不可289件は互いに重複せず、計算起点3,946件を覆う。公開サイトのOriginに対するCORSと、複数地域の実データ取得を確認。
- 2022年度のP11の利用条件は [国土交通省の当該データページ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-2022.html) でCC BY 4.0と確認し、PR側の計算起点カタログのPDL表記を訂正。レコード本体は変えていない。
- 新しい徒歩圏の道路・標高・加工方法・ODbLの表示を、既存の施設出典とともに出典ページへ反映。標高出典は [地理院タイル（標高）](https://maps.gsi.go.jp/development/ichiran.html#dem)。
- 道路抽出原本 `raw_data/yamaguchi-roads.json`、標高表 `raw_data/elevations.json`、P11原本と計算スクリプトを受領。今回、県内全域を再計算したり、コーディネーターのR2データを更新したりしていない。

## 確認結果

- 型検査、PRの計算・標高・切断・索引テスト、7地点の試算生成と新方式の不変条件、従来徒歩計算、全4,418件の起点対応、全5,560場所リンクと28条件リンク、道路原資料13項目、施設取込8テスト、施設検証が成功。
- 本番用R2 URLを含むビルドと18ファイルのリリース検査が成功。国の4,418レコード、OSM原本、従来徒歩圏、施設、比較用データと出典を維持し、R2の徒歩圏本体をサイトへ重複同梱しないことを確認。
- PC1280×900・スマホ390×844で国のスポーツセンター前の徒歩圏、凡例、施設検索・詳細への移動・元のバス停への復帰を確認。元の共有IDが保たれる。
- 従来のOSM地点2の5分・3kmで候補0件、4kmで1件となり、施設詳細からの復帰と再読み込みで5分・4kmが維持されることを確認。コピー成功表示も確認。実クリップボードからの貼り付けは従前と同様に未確認。
- 接続不可の地点は理由を表示し、コンソールエラーを出さない。検証用に徒歩圏ファイルを置かなかった地点では再読み込みボタンを表示し、ファイルを配置した後の再試行で徒歩圏が表示されることを確認。
- ローカル画面検査はR2の取得済みサンプルを同じ形式で配信する検証用ビルドで実施。本番OriginのCORSは別途確認し、マージ・公開後は実際の公開URLでも確認する。意図した欠損試験の404以外に実行エラー・警告なし。
