# 長府A保留・小月の説明訂正

## 訂正の結論
v14に記した「公式図のAは降車場の南側で、南北にある原2点の南側に対応」は公式図に一致しない誤記。画像には降車場の表示がなく、原2点を識別できる根拠は確認できなかった。別の公式資料を見た記録もない。この対応の確定を撤回する。座標の誤りと断定したものではない。
小月1・2の駅寄り／駅から離れた側という説明は逆であり、3の駅舎側という説明も撤回する。

## 表示と再発防止
長府の旧共有リンクは原IDのまま開ける設計で、「長府駅（番号対応未確認）」、公式Aとの対応未確認、徒歩圏・施設は表示しない旨を表示する。A番号バッジを外し、確認中の色にする。無関係な宇部の位置確認票へ誘導しない。原点の移動や別地点の結果の流用はしない。
長府の旧徒歩圏は有効indexから除外し、配信対象の取り込みからも除外。旧計算ファイルはソース履歴と data-sources/chofu-oduki-correction-20260915/withdrawn-node-6924153238.json に保持し、撤回理由を付けた。
再生成処理は保留地点を自動計算しない。旧indexが誤って復元されても、保留地点に徒歩圏を付与する処理はエラーで停止する。
