# 国土数値情報との比較結果（2026-09-09）

## 何を実施したか

国の山口県ファイル4,418レコードを、既存の比較マップに緑色で追加した。青は既存OSM1,085点、橙は光市172・岩国735の計907件。県全体・光市・岩国市へ移動でき、表示設定で3種類を個別に切り替えられる。点をタップすると各原本の名称・事業者または路線・時点・出典を表示する。通常の地図のデータは置き換えていない。

URL：https://yyy-yuichi.github.io/bus-stop-compact-town/review.html

## 比較で分かったこと

|確認する側|件数|相手の点が100m以内にある|うち同名の点が100m以内にある|
|---|---:|---:|---:|
|国 → 現在のOSM|4,418|751|601|
|現在のOSM → 国|1,085|952|826|
|光・岩国の採用候補 → 国|907|777|743|

国の3,667レコードには現在のOSMが100m以内になかった。現在のOSMに収録されていない範囲を探す材料になる。ただし同一地点の複数事業者、上下集約、改廃、名称変更等があるため、新しい物理的バス停が3,667か所見つかったという意味ではない。

比較は方向によって数が違う。国の1点の近くにOSMの上下2点があれば、国側では1、OSM側では2と数える。国の同一座標をまとめた数は3,946組だが、物理的なバス停総数とは断定しない。

## まだ判断できないこと

「国の方が位置精度が高い」とは、この比較では判定していない。地図上の近さ・名称一致は整合の目安で、現地の正解座標との比較ではない。現地精度を比較するには、公式の乗り場図や現地位置が確認できる地点を選び、道路の側と上下集約を揃えて評価する必要がある。

## 公式仕様と時点

[国の公式仕様](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P11-2022.html)では、現在公開されている最新版が2022年度版。元資料は概ね2022年8月で、資料ごとにばらつきがある。原則として同一道路の同一事業者・同名停留所を統合し、上下を集約。高速・デマンドバスは原則対象外。2022版の利用条件はCC BY 4.0。位置の品質検査は背景図の道路上かどうかの検査であり、現地の乗り場に対する測量精度を示すものではない。

## 方法と再現

9月8日取得済みZIP内のGeoJSONを使用し、座標・名称・事業者・系統・備考を保持。元資料に恒久的な停留所IDがないため、今回の原本行番号を含むIDを付けた。将来版との結合にはこの行番号を使わない。

原本の測地系はJGD2011（EPSG:6668）。原本座標を保持して経緯度として描画し、測地系・元期の補正は行っていない。距離は球面距離の概算であり、メートル単位の位置精度の優劣を判定する用途に使わない。

300m以内の候補を取得し、25/100/300mの近接と名称一致を集計。名称は全半角・空白・ヶ/ケだけを正規化し、鐵/鉄等の異体字や改称を推測統合しない。範囲外は距離空欄とし、最寄り距離を捏造しない。既存データや座標を上書き・自動統合していない。

`python scripts/compare-national-stops.py`で再現。21件の抽出サンプルについて空間検索の候補集合が全件総当たり検索と一致することを検査。出力CSV3種、集計JSON、原本ZIP、公開JSON、スクリプトを保存する。サイトの検証では4,418IDの一意性・年度・ライセンス・配布ファイル一致を確認する。
