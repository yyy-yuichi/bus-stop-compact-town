# 岩国市・由宇地区65地点の追加整理

## 対象と根拠

岩国市の生活交通・由宇地区バス公式GTFSの現行ファイル（feed start 2026-03-27、version `20260326_2026年03月26日（改正）`）を、既存地図の岩国市735原地点と原IDで照合した。公式800地点のうち、従来保留していた65地点を対象とした。

- [岩国市オープンデータ](https://www.city.iwakuni.lg.jp/soshiki/8/36369.html)：個別表示がない場合はCC BY 4.0
- [山口県オープンデータの岩国市GTFS](https://yamaguchi-opendata.jp/ckan/dataset/352080-gtfsjp)
- [由宇地区バス案内](https://www.city.iwakuni.lg.jp/soshiki/61/115174.html)
- 保存原本：`data-sources/iwakuni-directed-20260915/official-20260327.zip`

別に確認した「いわくにバス」事業者配布GTFS 238地点は、公式配布ページに二次利用条件を確認できなかったため、この追加には使用していない。GTFS形式であることだけを公開利用の許諾とは扱わない。

## 整理結果

- 既存の岩国市735地点：変更なし
- 新規追加：65地点、46名称
- 同名2地点：19組。19組すべてで公式GTFSの行先が異なり、原ID別に選択できる
- 乗車地点：64
- 降車専用：1（`iwakuni:630_02` 相地）
- 公式番号：原資料に値がないため追加なし
- 原座標：全65地点で公式GTFSと完全一致

同名19組38地点は、公式停車順・shapeと取得時点のOpenStreetMap道路線で個別に照合した。両地点を机上確認できたのは、公門所、千鳥橋、城ヶ崎、有家、神代駅前、長田公会堂前の6組。個別には19地点を確認できた。残り19地点は、進行方向の右側、分岐・曲折、左右差3m未満、起終点などの理由を原ID別に保留した。道路側の机上確認は現地標柱の確認ではない。

単独名称27地点も同じ方法で全便の通過方向を照合したが、新たな道路側確定は0地点だった。内訳は、同じ公式点で道路側判定が方向により反転する8地点、不整合のみで乗降側を確認できない2地点、曲折・分岐・起終点などで判定不能の17地点。単一の公式点から方向別の別位置を作る根拠はないため、27地点とも原点は保持し、徒歩圏は未計算とした。照合結果は `data-sources/iwakuni-yuu-singletons-20260915/classification.json` に記録し、地図の詳細説明にも原ID別の保留理由を反映した。

## 徒歩圏

道路側を確認した19地点だけを既存方式で計算した。

- 新規徒歩圏：13地点
- 道路側確認済みだが30m以内に歩行可能道路なし：6地点（31.7～72.0m）
- 既存徒歩圏：1,149件を再計算せず保持
- 現在の有効徒歩圏：1,162件
- 今回追加65地点のうち未計算：52地点

6地点は原点を道路上へ移動せず未計算とした。未計算52地点には、上記6地点、同名組で道路側を保留した19地点、道路側を照合したものの方向別位置を確定できなかった単独名称27地点を含む。
