# 光市・買い物の往復を現地で確かめる

対象は、ひかりぐるりんバスの光駅北口〜イオン光店。これは未実施の確認票であり、確認済みの旅行案内ではない。

資料上の例：2026-09-15、光駅北口の右回り10:08 → イオン光店10:19。帰りはイオン光店の左回り11:40 → 光駅北口11:51。大人往復400円。GTFSの行きID `7_01`、帰りID `7_02`、店舗バス停ID `10_01`。当日の運行は[光市の公式案内](https://www.city.hikari.lg.jp/soshiki/11/kokyokotsu/1/1/1936.html)で再確認する。

| 確認する場所 | 記録すること | 今分かっていること／不足 |
|---|---|---|
| 光駅北口・行き | 標柱の位置、右回りの表示、10:08便、待つ場所 | PDFは10:08、GTFSは10:07。試行計算は公式PDFを採用。道路のどちら側かは未確認 |
| イオン光店・到着 | 降車位置から食品売場の出入口までを往復別に計時 | 同じGTFS登録点を往復便が利用する。停車姿勢・進行方向・歩く側は未確認 |

実測欄：確認日＿＿＿＿／実際の行き乗車＿＿：＿＿／店舗到着＿＿：＿＿／行き徒歩＿＿分／使用した入口＿＿＿＿／買い物＿＿分／帰り徒歩＿＿分／停留所に戻った時刻＿＿：＿＿／帰り乗車＿＿：＿＿／北口帰着＿＿：＿＿／自宅まで＿＿分。

実測は、移動速度や荷物・天候の条件も添える。試行ページの初期徒歩10分を、誰でも歩ける時間へ置き換えて扱わない。確認後は、出典と確認日を付けて乗り場・入口・区間別の情報を更新し、入力値を変えて再検査する。

病院へ広げる場合は[公式1階図](https://hikari-hosp.jp/about/map.html)の正面エントランスまでの接続と診療科の受付条件を確認する。診療・検査・会計の所要時間は買い物45分に置き換えない。学校は現在の通用門と訪問条件の確認が先になる。
