# Drive保存で同じ停止・再作業を繰り返さないための手順

更新日：2026-09-25。バス停コンパクトタウンの006で確認した転送結果をもとに、非積算案件のDrive保存に適用する。積算案件への適用・転送許可を追加するものではない。

## 保存前に確認すること

- 案件の正式フォルダ、現在の正本、保存済みファイルID、直近の保存証明を確認する。保存済みのものをエラー表示だけで未保存へ戻さない。
- 原本のファイル名・バイト数・SHA256、収録ファイルの一覧とハッシュ、対象の実装コミットを記録する。転送だけの失敗を理由に、確定済みZIP・ソース・調査結果を作り直さない。
- 原本を別の一時作業場所へコピーする必要がある場合は、コピー前後のSHA256一致を確認する。正本の場所を変えない。秘密情報を含めない。

## 保存エラーが出たときの切り替え

1. まず保存先を再取得し、同名ファイル・ファイルID・サイズ・処理中のアップロードを調べる。タイムアウト後に完了している可能性も確かめ、重複送信を避ける。
2. 同じ条件の再試行や、根拠のない拡張子・分割サイズ・エンコード変更を続けない。経路、入力ファイルとハッシュ、エラー、保存先の実状態を短く記録し、次の試行で何を確かめるか決める。容量不足や権限不足は、内部エラーだけでは断定しない。
3. 利用中の連携で原本転送が失敗した場合、既存ログインのDrive画面と通常の「ファイルのアップロード」を利用できるか確認する。本件では、既存の5個のZIPボリュームをファイル選択ダイアログから送る経路で成功した。すでに検証済みのボリュームは再利用する。新しい分割物が必要なら原本を保持した派生物として作り、順序・サイズ・各ハッシュ・復元方法を用意する。
4. ブラウザーの進捗100%だけでは保存完了にしない。「アップロードが完了」の表示と、Drive側のファイルID・親フォルダ・サイズを確認する。操作が長時間戻らない場合も、別タブや同じ転送を増やす前に状態を確認する。
5. 既存の承認範囲で必要な転送・検証まで進める。新しい共有設定、認証変更、費用発生で回避しない。代替経路も利用できなければ、原本を保全し、未保存の対象と必要な次の操作を明示する。

接続済み連携はファイル一覧、メタデータ、小さな文書の保存、読み戻しにも使える。本件の一部のZIP転送が失敗した事実を、連携全体が使えないという判断に広げない。PC負荷を抑え、転送用ブラウザーは必要最小限にする。

## 完了を判定する検証

- 正式フォルダから保存物を取得し直し、ローカル原本とのバイト数・SHA256一致を確認する。
- 分割保存では、全ボリュームと一覧・復元手順を同じ正式フォルダに置く。Driveから取得したファイルだけで元ZIPを復元し、元ZIP全体と収録ファイルすべてのサイズ・SHA256を照合する。断片1個の保存を原本全体の保存と扱わない。
- 保存証明にファイルID、検証日時、照合結果、実装コミットを残す。実装完了・検証完了・正式保存完了・公開状態を別々に記録する。後から文書だけを更新したコミットを、凍結済み原本ZIPの実装コミットと混同しない。
- 次回の入口に保存証明と手順へのリンクを置く。追加した手順や更新した入口自身もDriveへ保存して読み戻す。失敗履歴や一時ファイルを削除する場合は、対象を示して別途ユーザーの承認を得る。

## 006で確認できた成功例

対象は実装コミット `b1caaf8ea555a710e9cdd42aeab1318c12bad888` の既存原本 `006-shunan-oz-verified-20260925.zip`。

| 確認項目 | 結果 |
| --- | --- |
| 原本サイズ | 5,113,369 bytes |
| 原本SHA256 | `4cb6e10317104840aab5dc5246b2ccd65631f07cd9951c8dde1723eb4f16d961` |
| 成功した転送 | Drive画面のファイル選択で既存ZIPボリューム5個をアップロード |
| 正式保存の確認 | Driveから5個を取得し、元ZIPを復元 |
| 内容の照合 | 元ZIP全体のSHA256一致、内部78ファイルのサイズ・SHA256一致 |
| 失敗原因 | 未特定。サイズ・権限・パスのいずれかと断定できる証拠はない |

連携APIでは元ZIPや複数の派生形式で `InternalError (-32603)` が発生した。一方、別の約1.4MB ZIPや小さな文書は保存できた。ブラウザーからの元ZIP一括送信も完了確認に至らず取り消した後、既存ボリューム5個で保存・復元検証まで成功した。この観測結果を切り替え判断に使い、一定サイズ以下なら必ず成功するという規則にはしない。
