# 買い物先と画面の更新（2026年9月11日）

## 今回の変更

バス停4,418件と買い物先22件を初期表示し、検索欄に名前を入れて選択・拡大できるようにした。買い物先はスーパー、ドラッグストア、商業施設の3種類で表示を切り替えられる。非表示の種類も検索対象に含め、検索結果を選ぶとその種類を再表示する。

白を基調とするヘッダーと検索・表示設定パネル、右側の詳細パネルに整理。幅1,000px以下では設定を折りたたみ、詳細を下側に表示する。買い物先のピンは「食」「薬」「買」で種類を区別する。店舗詳細から所在地、公式サイト、位置データの出典を確認できる。

[GovTech東京の記事](https://note.govtechtokyo.jp/n/n7e85b04335e5)に掲載された公開画面を、情報の整理と余白の参考にした。TokyoMapのロゴ・画像・ソースコードは使用せず、アイコンと画面は独自に実装した。

## データと継続作業

- `public/data/shopping.geojson`：既存19施設の座標・出典を保持し、分類だけを追加。新規3店と合わせて22件。建物12件、施設範囲2件、代表点8件。
- `scripts/add-daily-shopping.py`：保存したOSMから3店を再生成。同じIDを重複追加しない。
- `work/daily-shopping-20260911/shopping-source.osm`：該当3店と建物ノード13要素の原資料抜粋。位置・タグ・更新日時・版を保持し、編集者名等は除外。ソースZIPに同梱。
- `work/daily-shopping-20260911/source-manifest.json`：名称・住所の照合方法、公式URL、OSM IDと更新日時を記録。

OSM由来の施設位置と派生データはODbL 1.0。公式ページの写真や本文の転載は公開データに含めない。

徒歩圏は従来どおりOSMの7停留所とおのだサンパーク1施設のみが対象。今回追加した3店への徒歩経路・到達可否は未計算。国土数値情報の4,418件を徒歩圏に接続する処理、乗り場別の補完、県内の店舗網羅調査は今回の対象外。

## 確認した操作

内蔵ブラウザーで1280×720、390×844、820×900の表示を確認。店舗・バス停の名前検索、種類の切替、非表示種類の検索からの再表示、店舗の建物・代表点詳細、スマホの設定展開、国データと徒歩圏試作の往復、5分・10分表示と候補へのスクロールを確認した。画面幅を変えた際も選択地点がパネルの間に表示される。

キーボードで検索欄→Tab→検索結果→Enter→詳細→Escape→検索欄の往復を確認。主要操作には名前と選択状態を付与。配色は文字と背景のコントラスト、種類の区別は色に加えて文字でも表現。全ページのWCAG適合認証を行ったものではない。ブラウザーの実行エラーログは確認時0件。
