# 追加候補の確認マップ

URL：https://yyy-yuichi.github.io/bus-stop-compact-town/review.html

通常の地図を置き換えず、同じLeaflet・OSM背景を使った独立ページで比較する。初期表示は光市の候補範囲。上部の地域ボタンは表示範囲の移動で、行政界による絞り込みではない。

- 青：既存OSM1,085点
- 橙：公式候補907件（光172＋岩国735）。重複未統合であり、新設地点数ではない。
- 地域ボタンで光市・岩国市・両地域へ移動。「表示設定」で各レイヤーを切り替える。
- 点をタップすると名称・原本ID・路線名・データ時点・出典が開く。情報欄は点をタップした時だけ表示する。

由宇改正関連65件は除外。周南・下松の2024年103点もこの試験表示には含めない。徒歩圏の計算・地図基盤の選定はコーディネーター担当で、このページはデータの見え方を確かめるためのもの。

公開データはpublic/data/review-stops.geojsonとreview-routes.json。元はDrive保存済みstop-handoff-20260909-v2.zip（ID：12LKbvTJ8YjyGk7Bl48n9UdZ1BkCtBQe2）。公式点の座標は原本のまま、重なりを避けるための位置移動やID統合はしていない。

PC幅および390×844のスマホ幅で、地域移動・レイヤー切替・光の浅江中学校前／岩国の北河内駅の名称と路線の表示を確認。型検査・19施設検査・ビルド・配布物の検証に加え、候補907件の一意性、光172／岩国735の内訳、由宇関連除外、路線参照、公開ファイルの一致を検査する。原本の日付は2026年4月で、現在の運行状況や現地の乗り場確認とは区別する。
