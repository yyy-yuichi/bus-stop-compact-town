## Jevは何を効率化したか

山口県公式一覧→15市町一覧→65店舗・薬局ページを取得し、既存ID候補との組を一括分類しました。[県内公式一覧](https://shop.tsuruha-g.com/yamaguchi)。

| 工程 | 実測・確認結果 |
|---|---|
| Jev追加処理 | 65対象、9通信、jev-1.13.0 |
| 実行時間 | 6.142秒（API通信合計5.927秒）。収集・一次照合・実装・保存の総時間ではない |
| 使用量からの推定費用 | $0.005429970。請求明細との突合は未実施 |
| 完了後の再実行 | 9通信を保存応答から再利用、追加送信0 |
| 公式65掲載の最終整理 | 54物理店舗＋11併設調剤薬局。54店舗＝追加39＋既存照合13＋保留2 |
| Jev分類から修正したもの | 17/65。主に店舗と併設薬局の取り違え。独立した正答率試験ではない |

Jevは候補の振り分けで、営業事実の確定器ではありません。今回も生応答、17件の修正前後、採用・保留、元ID、資料ハッシュを残しました。次回は同住所の併設関係を決定的な前処理で分けてから、曖昧な同一性をJevへ渡します。人が一件ずつ検索する速度に全体を戻さず、公式一覧単位の一括取得と、未掲載・重複・旧新店の差分照合を続けます。

承認3,000対象/$1（既存クレジット、購入・自動チャージなし）の累計は1,919対象、使用量推定$0.108968034、保守的予約額$0.558759936。残り1,081対象/$0.441240064。過去100対象試験は別枠。

実行器の汎用集計には過去試験向けの `limitation` 文言が残っています。この65件の実入力は当日取得した公式店舗ページと元施設候補です。完了済みの入力・生応答のハッシュを変えず、今回集計の `scope_note` でこの相違を明示しました。

## 判断基準の改善

- 閉店確認済みでも日付が不明なら、`closed`＋`effective_at:null`＋`date_precision:unknown`。ミコーは年月まで確認したため`2025-01`。年月の年は2025年の公式記事の文脈によることを明示。[後継店運営者の報告](https://marukyu-saiyo.jp/news/丸久熊毛店オープンについて/)。
- 告知の掲載日を閉店日に代用しない。小野田・光浅江は公式の閉店事実で候補から外し、正確な閉店日は未確認と表示。[小野田公式告知](https://www.wants.co.jp/news/close_3679/)、[光浅江公式告知](https://www.wants.co.jp/news/close_3694/)。旧所在地のメーカー取扱店案内は同一店舗の照合だけに使い、古い営業案内を現況へ採用しない。
- 店舗と同住所の調剤薬局11掲載を二重に施設追加しない。薬局の公式リンクと検索名は残し、営業時間が同じとは扱わない。県外店・別支店・商業施設本体も混ぜない。
- 位置は公式店舗のJSON-LD、または公式ページから案内された地図の店舗・建物代表点。地図の画面中心を店舗位置に使わない。入口・徒歩到達性は未確認。
- 公式一覧から消えたことだけでは閉店扱いにしない。別名の旧店舗、元データ内の重複は保留する。
