# 生活施設追加と背景地図改善（2026-09-13）

ユーザーが承認した「情報を増やす」「マップ自体をもっとカッコよくする」を実装した。郵便局・銀行などを徒歩圏の候補へ追加し、背景地図を淡い青緑と生成りの日本語地図へ変更した。

## 追加した情報

通常の利用候補に郵便局417件、銀行118件、図書館56件、役所・支所60件、公民館・交流施設132件、計783件を追加。新規の参考記録9件も保存し、施設全体は1,927レコード。参考14件を除く1,913件が通常表示の対象。名称・登録住所による検索、分類表示、共有、国のバス停からの徒歩5/10/15分候補に対応した。候補は「すべて・買い物・医療・暮らし」で絞り込める。

新しい792件はOpenStreetMapの登録情報で、現在の営業状況や入口を個別確認したものではない。2026年9月13日に取得したレスポンスの基準日時は2026年7月28日02:16:18 UTC。住所未登録や確認状況は施設詳細で区別する。原本、クエリ、取得記録、除外理由を保存した。既存1,135施設と5,325バス停の原本ID・座標・属性は維持した。道路の再計算やR2の設定変更は行っていない。

公開前に閉鎖・旧施設を示す名称と日本郵便の2026年山口県向け告知を照合した。廃止6局・一時閉鎖中または再開前2局と仮庁舎1件は通常候補から外し、理由・出典・元のIDと位置を参考記録として保持。将来の閉鎖・移転告知2件は予定日と再点検の必要を記録し、現在の分類・位置を維持した。すべての施設の営業確認を済ませたものではない。対象と根拠は [点検原本](../data-sources/life-facilities-20260913/reviews.json)。

## 地図の変更

| 比較対象 | 実画面での確認・判断 |
| --- | --- |
| 従来のOSM | 情報は豊富。軽い表示の選択肢として維持。 |
| 地理院淡色 | 日本語・地形情報が充実。今回の暮らしの施設を中心に見る地図では背景情報が多いため不採用。 |
| OpenFreeMap Liberty | 色と地物が豊富。バス停記号がアプリの記号と重なるため不採用。 |
| OpenFreeMap Positron | 背景の情報を整理しやすく、配色・文字を調整して採用。 |

日本語を優先し英語との二重表記を抑え、陸地を生成り、水面を青緑へ変更。小さい地域名・鉄道・駅名の見分けを補った。徒歩圏表示中の白い重ねを50%から25%に薄め、道路の強調と背景の地名を両立した。表示設定で「やわらか」「標準（軽い表示）」を選べ、選択はブラウザーへ保存する。常設の操作パネルや地域ボタンは増やさない。

ベクトル地図は必要時に読み込み、worker1つ・タイルキャッシュ32枚・pixelRatio最大1.5とする。MapLibre GL JS 6.9.0とアダプター0.1.4を固定。既知の問題がある旧版は採用せず、npmの監査は0件。スタイルとworkerの配信を検査し、描画できない端末や取得エラー時は従来のOSMへ切り替わる。

[OpenFreeMapの公式導入資料](https://openfreemap.org/quick_start/)、[スタイル原本・ライセンス](https://github.com/hyperknot/openfreemap-styles)、[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)、[MapLibreの公式設定](https://maplibre.org/maplibre-gl-js/docs/)を確認。地図の出典と加工したデザインの権利表記・ライセンス全文を公開サイトに含めた。

## 検証

- 従来1,135施設の全属性・形状と追加792件の再生成、同一出典IDの重複防止、原本SHA-256を確認。
- 5,325バス停ID・座標・路線、7,259場所リンク、従来28徒歩条件と国13,254徒歩条件が成功。
- 道路と施設の位置関係、25m境界、坂道・迂回距離、ポリゴン・穴・交差、5/10/15分の包含関係を検査。実データ10地点で従来候補数が変わらず、追加候補も実際の道路距離に一致。
- 地図スタイル56レイヤーの形式、型、従来徒歩計算、原道路の通行制限、本番ビルド、公開用24ファイルの原本一致とworkerの単独配信を確認。
- スマホ390×844で新しい地図、検索、光駅の時間切替、暮らし分類、光浅江郵便局の詳細往復、背景切替と保存を確認。光駅の候補は5/10/15分で2/3/8件。15分では銀行と郵便局が加わり、暮らし2件。
- ローカルの徒歩圏UI検証は既存の保存済み配信原本を利用。R2は公開サイトの接続元を許可しており、ローカルからのGETを許可しないため。公開後に本来の接続元で確認する。
- WebGLを使えない状態とスタイル503をそれぞれ再現し、標準地図への自動切替、徒歩候補の維持、描画の再試行を確認。
