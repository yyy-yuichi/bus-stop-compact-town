# Jevによる高齢者向け使いやすさの初回評価

2026-09-20、本人限定サイトを390×844 CSS pxで開き、初期画面、城下町長府のバス停詳細、施設詳細の3状態を確認した。DOMから測定した寸法、表示文字、操作手順を `request.json` のstateへ記録し、同じファイルの10問をTypeSafe Playgroundの `jev-latest` へ1回送った。

実行モデルは `jev-1.13.0`。入力3,059トークン、出力275トークン、評価時間161.48ms。画面表示単価（入力100万トークンあたり$0.042、出力無料）による推定費用は約$0.000128。

## 結果

| 評価項目 | 結果 |
| --- | --- |
| 高齢者が一人で中核操作を進められる可能性 | 2.71 / 4、confidence 65% |
| 選択中のバス停の明確さ | true 90% |
| 徒歩時間切替の分かりやすさ・押しやすさ | true 79% |
| 色を使わない施設分類の識別 | true 90% |
| 施設詳細から元のバス停へ戻る操作 | true 90% |
| 主要情報の読みやすさ | mixed 88%、comfortable 12% |
| 地図の表示密度による混乱 | moderate 98% |
| データ時点と確認注意の明確さ | true 82% |
| 現機能による中核目的の達成 | true 90% |
| 最初に検証すべき改善領域 | navigation 74%、text size 15%、map density 7% |

この結果は実画面を見た高齢者の回答ではない。Jevは画像自体ではなく、こちらが抽出した画面状態を評価している。改善前後を同じstate形式・質問・表示幅で比較するための基準として使い、地域利用者の操作確認と照合する。

## ファイル

- `request.json`: Jevへ送った評価状態と質問
- `response.json`: Playgroundから取得した応答、利用量、request ID
