# 岩国市・光市の表示と確認用サンプル

通常マップへ市の採用済み907レコードを接続する際に、近くの国の計算起点へ移る操作を確認した。市の原本は `public/data/review-stops.geojson`（岩国市735・光市172）、収録路線は `public/data/review-routes.json`。既存ファイルのID・座標・路線参照を変更していない。国の4,418レコードへの自動統合はしない。

今回取得した2つのJSONは、国の起点からの公開済み徒歩圏であり、市の登録点から再計算したものではない。取得URL・時刻・サイズ・SHA-256を `samples.json` に保存。`.gitattributes` で改行変換せず原応答を保持する。

|市の登録点|移動先の国のレコード|直線間隔|5/10/15分の候補数|
|---|---|---:|---|
|北河内駅 `iwakuni:i-319_01`|`mlit-p11-22-35:1379`|約27m|0 / 0 / 0|
|光駅 `hikari:1_01`|`mlit-p11-22-35:3791`|約37m|2 / 3 / 6|

候補は近くの道路までの時間であり、入口への経路や通行可否を確認した数ではない。市の浅江中学校前 `hikari:9_01`・`hikari:9_02` には300m以内の接続済み国の起点がないため、代替の徒歩圏を表示しない。

徒歩圏JSONは既存の配信と同じODbL 1.0。© OpenStreetMap contributorsの道路データと国土地理院の標高タイルを加工。元の国の起点は国土数値情報2022年度版（CC BY 4.0）。R2のデータ・設定の変更、全件再計算は行っていない。
