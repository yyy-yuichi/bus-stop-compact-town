# 光市の1路線・資料照合の原本

確認日：2026-09-14。光市のひかりぐるりんバス、光駅〜イオン光店の10停留所を対象に、GTFSと公式PDFを照合した。各社の資料入口の棚卸しは17の原本事業者名と光市の現在の運行事業者を対象とし、県内全便の現況確認を意味しない。

- `352101_kotsu001.zip`：光市のGTFS原本。172停留所ID、7路線ID、63便ID。期間2026-04-01〜2027-03-31。発行者は光市、実際のぐるりんバス運行は周南近鉄タクシー光営業所。
- `352080-gtfsjp.zip`：岩国市生活交通・由宇地区のGTFS原本。800地点のうち65は親停留所、735は乗り場。46路線ID、267便ID。期間2026-03-27〜2027-03-26。今回の試行計算には使っていない。
- `*-metadata.json`・`gtfs-catalog.json`：県CKAN公開元のメタデータ。美祢市のGTFSは非公開と明記、平生町は町営バスなしと明記。検索タイトル数と取得可能なデータ数を区別する。
- `gururin_*.pdf`：光市の2026年4月1日改正時刻表と路線略図。
- `gururin-pdf-check.json`：画像から独立して転記した10停留所×6便。北口10:07→公式10:08の1時刻、右回り7:40・15:45の年末年始運休条件2便を照合。元GTFSを改変せず計算用データに補正と元時刻を保持する。
- `facility-review.json`：既存4記録の名称・利用条件・旧所在地の見直し。IDと図形は保持。イオンの食品売場は1階、フロア図の正面北側・東側出入口を確認。病院は1階図の正面エントランスと中央受付を確認。いずれも地図上の入口座標と歩行経路は未照合。
- `transport-source-review.json`：各社の公式資料URL、確認できた範囲と残課題。公開用JSONへ2022年度原本レコード数を結合する。
- `*.receipt.json`：取得URL・取得日時・ファイルサイズ・SHA-256。店舗・病院のページ本文、フロア図、および解析用中間JSONは正式DriveのソースZIPに保存し、公開Gitやサイトには同梱しない。図面画像は再配布せず公式ページへリンクする。

再生成はプロジェクト直下で以下を実行する。取得済み原本の再取得・削除・更新は必要ない。

```powershell
python scripts/build-route-living-pilot.py
python scripts/apply-route-facility-review.py
node scripts/test-route-living.mjs
python scripts/verify-route-sources.py
npm run build
```

`verify-route-sources.py`は今回の元コミットと比較し、施設5,065件の全ID・図形が不変、属性の変更が指定4件のみ、他の9ファイルの内容が不変（GitのLF/CRLF変換を除く）であることを検査する。本文・図面の全取得照合には、DriveのソースZIPを利用する。

GTFSと光市の配布データは公開元のCC BY表記に基づく。OSM由来の位置・図形はODbL 1.0を維持する。公式ページ・館内図の著作権は各発行者に帰属する。出典URL・照合日・事実の要約を公開し、現在の歩行可能性や最新の営業状態の保証には使わない。
